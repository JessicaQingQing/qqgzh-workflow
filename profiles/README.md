# 配置你的职业资产工坊

把你自己——你的经历、你的资产、你想写什么、写给谁——写在一个 JSON 文件里。改它就是换一个人。

---

## 在哪里

```
profiles/
└── example/
    └── profile.json    ← 复制一份，把示例信息改成你自己的
```

---

## 怎么改

**最快的方式：跟 AI 聊，让 AI 帮你写。** 不需要手动改 JSON。在 AI 里说你是做什么的、干了多久、想写什么方向，AI 会问你几个问题然后帮你填好。

**或者直接改：** 把 `profiles/example/profile.json` 复制一份，发给 AI，说：

> "帮我把这个改成我的配置。我做了 XX 年 XX，最擅长的是……想写给……"

## Profile 结构

### `identity` — 你是谁（核心必填）

| 字段 | 说明 |
|------|------|
| `name` | 你的名字或笔名 |
| `professional_background` | 一句话说清你干什么、干了多久 |
| `key_experiences` | 3-8 件你做过的事——每件包含具体事件、体现的能力、有什么外部证据、是"确认的"还是"还在验证" |
| `voice` | 你说话的风格（比如：接地气、有判断、直接） |
| `avoid` | 你不想用的写法（比如：空洞术语、贩卖焦虑） |

### `content` — 你想写什么（核心必填）

| 字段 | 说明 |
|------|------|
| `directions` | 你的内容方向——每个方向包含描述、写给谁、典型题目、当前状态 |
| `topic_bank` | 你的选题库——每条包含题目、类别、从哪段经历来的、当前状态 |

方向状态：`active`（在写）/ `testing`（试试看）/ `parked`（暂时搁置）
选题状态：`seed`（想法）/ `outlined`（有提纲）/ `drafted`（有初稿）

### `brand` — 公众号信息（可选）

如果你还没有公众号，这部分可以空着。以后有了再填。

| 字段 | 说明 |
|------|------|
| `name` | 公众号名 |
| `tagline` | 一句话介绍 |
| `style_notes` | 文风偏好 |

### `channels` — 发布渠道（可选）

目前只支持微信公众号。按需配置。

### `connection` — 读者连接（可选）

| 字段 | 说明 |
|------|------|
| `enabled` | `true` 或 `false`——是否在文章底部加读者连接入口 |
| `invitation` | 关注引导文案（仅 `enabled: true` 时生效） |
| `offers` | 你的产品或服务（暂时没有就空数组 `[]`） |

很多人在探索阶段不需要读者连接入口——关掉就好，文章照样发。

### `publishing` — 发布设置

| 字段 | 说明 |
|------|------|
| `requires_explicit_confirmation` | 必须为 `true`——每次发布前都要你亲口确认 |

---

## Profile v1 迁移到 v2

如果你有旧版本的 Profile（v1），结构从"品牌优先"变成了"人和经历优先"。旧版可以继续用，但建议迁移到 v2 以获得完整体验。让 AI 帮你迁移——把你的旧 Profile 贴给 AI，说"帮我升级到 v2 格式"。

---

## 私密信息

真实客户资料、发布凭据放 `private/` 文件夹，不会被打包上传。职业经历里的具体事件可以模糊公司名、人名等可识别信息，保留问题、动作、判断和结果即可。
