# 品牌配置

把你公众号的品牌信息写在一个 JSON 文件里。改它就是换品牌。

---

## 在哪里

```
profiles/
└── example/
    └── profile.json    ← 打开这个，改掉示例信息
```

---

## 怎么改

**最快的方式：跟 AI 聊，让 AI 帮你写。** 不需要手动改 JSON。在 AI 里说你想做什么方向的号，AI 会问你几个问题然后帮你填好。

**或者直接改：** 把 `profiles/example/profile.json` 发给 AI，说：

> "帮我把这个改成 XX 博主的配置。公众号叫 XX，读者是 XX，文风偏好 XX。"

---

## Profile 六个部分

| 部分 | 干什么 |
|------|--------|
| `brand` | 公众号名、Slogan、文风、不想用的写法 |
| `audience` | 你的读者是谁、需要什么 |
| `visual` | 品牌色、配图风格（不配图不管） |
| `connection` | 文章底部固定关注+私信引导 |
| `monetization` | 你的产品或服务，没产品可以空着 |
| `publishing` | 发布模式，不用改 |

---

## 私密信息

真实客户资料、发布凭据放 `private/` 文件夹，不会被打包上传。
