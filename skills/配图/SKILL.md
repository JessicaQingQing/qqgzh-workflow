# 文章配图（可选）

配图是**可选的**。这是公众号发布层的视觉适配器——只在用户要把内容发布到公众号且需要配图时使用。没有生图工具、没有微信图床、不会搞图片——这一步直接跳过。审查不会因为没图而拦你。

## 三种路子，选你顺手的

### 路子一：不配图（最省事）

直接说"这篇不配图"。审查不查图片数量——只查已有的图片链接安不安全。没有图片就没有可查的，直接过。

### 路子二：自己画 + 传到微信

1. 用 Canva / Figma / PPT 做好图。
2. 打开微信公众平台 → 素材管理 → 上传图片。
3. 拿到 `https://mmbiz.qpic.cn/...` 格式的链接。
4. 填进 HTML 的 `<img src="...">` 里。

### 路子三：AI 生图 + 传到微信

1. 从 Profile 的视觉配置拿风格方向。
2. 参考 `references/visual-system.md` 写生图提示词。
3. 用 Midjourney / DALL·E / 豆包 / ComfyUI 出图。
4. 上传到微信图床，拿到 `mmbiz.qpic.cn` 链接。
5. 填进 HTML。

## AI 生图的话，注意几条

- **提示词必须先让你确认再去跑**，不能自己闷头调 API。
- **不静默换模型、不静默换图床**——换什么都得先问你。
- 只保存最终的提示词和图床链接，中间产物不往包目录里堆。

## 图片尺寸

| 类型 | 尺寸 | 说明 |
|------|------|------|
| 封面 | 900×500 | 文章头图，分享时候显示的那张 |
| 内页 | 1080×540 | 正文里的插图或示意图 |

## 别踩的坑

- 不用客户照片、内部资料、私人素材——除非你的私有层有明确授权记录。
- 所有图片链接必须是 HTTPS 且在白名单域名里。
- 版权和肖像权的事情，自己心里要有数。
