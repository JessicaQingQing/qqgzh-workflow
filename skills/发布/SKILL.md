# WeChat Publish — 对话式发布引导

你已经有了审查通过的 HTML 文章。接下来这一步不是冷冰冰的"你自己贴去吧"——我陪你走完最后这一段。

## 先别急着发——聊两句

在告诉你怎么发之前，我先了解你的情况：

1. **你的公众号是什么类型？**
   - 个人订阅号（自己注册的，每天能发一篇）
   - 企业服务号（认证过的，API 权限更多）
   - 还在注册/还没注册——想先看看效果

2. **你平时怎么发文章？**
   - 打开微信后台，粘贴 HTML → 预览 → 群发
   - 还没发过，这是第一篇
   - 想试试自动推草稿，不想每次都手动贴

3. **这篇你想怎么处理？**
   - 先预览一下手机效果再决定发不发
   - 直接发
   - 存草稿，明天/过几天再发

## 根据你的情况，我给你最合适的路线

### 如果你有认证服务号 + 想自动推送

**你可以让 AI 直接把草稿推到微信后台，不需要手动粘贴。** 只需要配置一次：

1. 登录 [mp.weixin.qq.com](https://mp.weixin.qq.com) → 设置与开发 → 基本配置 → 拿到 `appID` 和 `appSecret`
2. 把这两个值写入本地 `.env` 文件（`.gitignore` 已排除，不会上传到 GitHub）
3. 在公众平台 → 基本配置 → IP 白名单，加上你运行脚本的服务器 IP
4. 配好之后跟 AI 说"帮我推到草稿箱"——草稿就到微信后台了，你扫码预览确认就行

> ⚠️ 每次只推到**草稿箱**，不自动群发。群发那一步必须你自己在手机上确认。这样可以先预览、先测试、没问题再发。

### 如果你是个人订阅号

个人号 API 权限有限，草稿 API 大概率调不通。没关系，**手动粘贴也是最快的路**：

1. 打开 [mp.weixin.qq.com](https://mp.weixin.qq.com) → 登录
2. 左侧「图文消息」→「新建图文」
3. 在编辑器工具栏最右边找到 **「源代码」** 图标（`</>` 那个）
4. 把上面生成的 HTML **全选复制** → 粘贴进去 → 点「源代码」切回来
5. 点「预览」→ 发到自己手机上看看效果
6. 没问题就「保存并群发」

> 💡 **小提示：** 第一步可以先用草稿箱的"预览"功能发到自己微信看效果。不用直接群发。手机上确认格式没问题了再正式发。

### 如果你还没注册公众号

先不用管发布。我帮你把 HTML 存好——等你的号注册好了，打开文件就能发。你现在可以先在浏览器里打开 HTML 文件看效果。

## 发布前最后确认

不管是手动还是自动，发出去了就收不回来。发之前你确认三件事：

1. **手机预览过了吗？** 标题折行吗？金句框窄屏好看吗？图片裂了吗？——电脑上看着对，手机上不一定对。
2. **内容你读完了吗？** 不是扫一眼。是逐字读完。错别字、数据、人名——发完再改就得删文章重发。
3. **这篇要放到哪个话题标签下？** 微信的话题标签能帮读者找到你的历史文章。

如果你还没准备好，跟我说"先存草稿"，我把 HTML 保存下来，你随时回来发。

## 发完了

跟我说一声"已发"。我可以帮你记一下：
- 这篇发了什么话题
- 用了什么暗号（如果你有暗号体系的话）
- 发了之后的反应——帮你慢慢积累"什么话题读者更感兴趣"

这不是必须的，但你如果想认真做号，有一个记录会很有用。
