# Privacy Rules

- Treat profiles as private inputs, never public package content.
- Keep brand identifiers, customer data, assets, recordings, credentials, and connection details outside releases.
- Do not put local paths, credentials, internal recordings, or private URLs in HTML, prompts, examples, logs, or screenshots.
- Publish only after user review, audit PASS, and explicit confirmation.
- Use fictional examples in public documentation and tests.
- If sensitive material appears, remove it, rerun audit, and obtain a new confirmation for the corrected revision.
