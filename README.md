# 青青的公众号 AI 工作流

**一套 AI 能读懂的公众号写作搭子——从不知道写什么，到写出自己的风格，到排版编辑审完直接能发。**

---

## 帮你解决什么问题

**💭 想做号，方向定不下来**

不用对着一张白纸想定位。跟 AI 聊你干过啥、帮别人解决过啥，聊着聊着方向就出来了——跟你朋友帮你捋思路差不多。

**✍️ 看到好文章想学，但打开空白文档就卡住**

把喜欢的文章链接扔给 AI，它当你面拆开——开头怎么钩的、节奏怎么控的、带货怎么引的——然后问你哪些你要、哪些不合你风格，照着骨架填你自己的肉。

**🧱 AI 写出来的东西全是字，一堵墙，手机上划三屏还没到头**

内置一箱子排版组件——金句框、小卡片、对比表、步骤条——写到该打断的地方自己插进去，读者不累。

**😰 发之前反复看，总觉得哪不对，又说不上来**

六项自动安检：微信会吞的 CSS 全滤掉、图片链接会不会裂、有没有不小心露出不该发的、结构完不完整——全绿灯才放行。

**💰 想带点货，又怕写成广告掉粉**

没东西卖不强塞。有东西卖了，观点写在前、身份放在后，占全文不到五分之一，读完了自然想往下翻——不硬。

**📨 文章发了没人找你，跟白写一样**

每篇屁股自动带上关注入口 + 私信暗号，读者看完知道你是谁、怎么找你聊。

## 怎么用——三种方式，不管你会不会用 Agent 都能用

**方式一：Skill 版（Claude Code / WorkBuddy，完整体验）**

```
/plugin install qqgzh-workflow
```

装完就能用，AI 自动读取整个 `skills/` 目录里的所有规则，六个 Skill 自己排队自己串。你不用一个一个指——跟 AI 说你要干嘛，它自己去找对应的 Skill。

| 说这句 | 干什么 |
|--------|---------|
| **"帮我聊聊公众号方向"** | 定位探索——AI 跟你聊经历、聊专长，聊出方向帮你写 Profile |
| **"帮我仿写一篇文章"** | 贴链接（或全文），AI 拆解写法、问你要什么不要什么、照着结构写你的内容 |
| **"帮我写一篇关于 XX 的文章"** | 给话题，六步自动串完——软广判断→排版→审查→发布 |

三个短语覆盖所有场景。

**方式二：Chatbot 版（腾讯元器 / 微信公众号）——即将上线**

公众号对话版正在搭建中，预计先上两个功能：定位探索（跟 AI 聊你的经历，聊出公众号方向）和初稿生成（给个话题，先出一版草稿）。排版、审查、发布这些需要完整工具链的环节，还是走方式一 Skill 版最顺。

上线之后会在公众号「**青青的AI组织观察笔记**」菜单栏放入口。想第一批试用的，先关注着等通知。

**方式三：知识包——拿去做你自己的**

如果你不愿意用我的 Skill，或者用的是其他 AI 工具（DeepSeek / Kimi / 豆包 / ChatGPT / Codex / Cursor / Trae），我把所有规则公开成了独立的知识包。

这些 `.md` 文件不依赖 Skill 框架——你可以把某一份贴到你的 AI 提示词里，也可以拿去做 RAG，也可以只当文档读。

怎么用都行。许可证是 **CC BY-NC 4.0**：个人使用不需要署名，公开发布注明来源就行，商用需要单独授权。

## 包里有什么

你不用翻文件夹，AI 自己会读。一眼扫过去知道每个是干嘛的就行——**带 ⭐ 的跟你有关系，其他的不用管。**

```
skills/  ⭐         ← AI 读的就是这里。六个 Skill 自动排队，你一句话它全串起来
 ├── 主入口          → 门铃——识别你要仿写、聊定位、还是直接写
 ├── 软广判断        → 这篇带不带货、带什么、怎么带不硬
 ├── 排版            → 微信兼容 HTML，从组件库里拣版式拼出来
 ├── 配图            → 可跳过；要配的话教你拿不裂的图链
 ├── 发前审查        → 六项安检，全绿灯才放
 └── 发布            → 陪你走最后一公里，手动粘贴或自动推草稿箱

references/          ← 排版组件库、微信 CSS 白名单、去 AI 味写作指南、软广方法论
                     ↑ skills 干活时自己会翻，你不用看

profiles/  ⭐         ← 你的品牌配置——公众号名、作者简介、强调色、关注引导
                     ↑ 第一次用的时候让 AI 跟你聊着填，以后就不用管了

templates/           ← HTML 骨架、发布确认模板
examples/            ← 跑通的示例文章，可以看看长什么样
scripts/             ← 校验和审查脚本（测试用，你用不上）
tests/               ← 自动化测试（你用不上）
.github/             ← CI/release 配置（你用不上）
.claude-plugin/      ← Claude Code 插件的注册文件（你用不上）
private/             ← 留给你放不想上传的东西，默认加入了 .gitignore
```

就这点东西。**你只需要操心 `skills/`（AI 替你读了）和 `profiles/`（聊一次就填好了）。**
