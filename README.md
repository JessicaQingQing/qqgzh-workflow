# 青青职业资产工坊 · Career Asset Studio

**帮有专业积累的职场人，把散落的经验变成看得见的职业资产和可持续的内容输出。**

属于「**青青搭子**」系列——这是一套产品族，微信里的「青青职场搭子」陪你聊、帮你理清思路，Claude Code 里的「青青职业资产工坊」陪你做、帮你把思路落成资产和内容。以后还会有别的搭子。

不是又一个"AI 写作工具"——是把青青 10 年 HR + 心理学科班 + 创业 + AI 陪跑中沉淀的方法，做成了 AI 能执行的对话式工作流。陪你从"我这些年到底值什么"走到"我知道写什么、怎么写、发给谁"。

## 为什么叫"职业资产工坊"

大多数内容工具解决的是"怎么写"——排版、配图、改错别字。但那已经是最后一步了。

**真正卡住人的问题在前面：** 干了这么多年我到底积累了什么？这些东西值不值钱？除了写公众号还能干嘛？为什么每次想写都得从头憋？

青青在 10 年 HR 和人才发展工作中反复看到同一个模式——有能力的人往往最看不见自己的能力。因为那些判断、方法、关系处理，对他们来说太自然了，自然到不觉得值得写。

**这个工坊做的事，是把"隐性专业积累 → 可表达的资产 → 可持续的内容"这条路，做成了一套 AI 能陪你走完的四层方法。**

## 核心方法：四层递进，层层有产出

```
第1层 · 价值探索          第2层 · 资产与方向          第3层 · 内容创作          第4层 · 渠道发布
  ↓                         ↓                         ↓                         ↓
从"不知道有什么可写"      从散落的故事到分类资产     从选题到结构确认的        HTML排版 → 多项安检
到3-8件具体的事            聚焦方向+选题清单           初稿生成                    → 发布
  ↓                         ↓                         ↓                         ↓
产出：职业资产快照         产出：方向卡/资产清单       产出：纯文字初稿          产出：可发的公众号文章
```

**四层不是四个功能——是一套从模糊到清晰的认知递进。** 每一层解决一个阶段的真实卡点，每一层有独立交付物。用户从哪层进来都行，不需要走完全程。

### 第 1 层：价值探索——"别问技能，问具体的事"

**底层洞察：** 人不是没有资产，是对自己的资产习以为常。问"你有什么优势"一定答不上来，问"上次谁因为什么谢你"能讲十分钟。

- **五组挖掘问题**：从"别人谢过你什么""你教新人什么""什么事总来找你""好与差的区别在哪""什么大家说但你不同意"——五条路径找到素材
- **四步追问法**：每件事追到场景→动作→判断→结果，不留在"我做过 XX"的表面
- **降级设计**：用户说"不知道"时，不重复追问同一道填空题，而是换成 3-4 个场景选择题
- **阶段小结机制**：不连续盘问十轮，每 3-5 轮给一次收获反馈——"你刚才说的这几件事，背后是同一种判断"

### 第 2 层：资产盘点与方向——"从一堆故事到一张地图"

**底层洞察：** 素材只有归类了才是资产，方向只有被验证了才算方向。

- **五大资产类别**：经验案例 / 判断框架 / 反常识观察 / 失败复盘 / 关系洞察——不是学术分类，每种对应一种写作价值
- **10 题测试**：一个内容方向能不能持续写？随口说出 10 个具体题目就知道了。说不出来就是太窄或太飘
- **A/B 分叉**：用户选"先定方向马上写"走快速收敛路径，选"盘全部家底"走完整清单路径——同一起点，不同终点
- **空词拆解**：用户说"我要做个人 IP""我想定位"时，不顺着大词往下滚——钉回具体场景：你想被谁以什么理由记住？

### 第 3 层：内容创作——"先确认，再动笔"

**底层洞察：** AI 写作最容易翻的地方，是替用户脑补了他没说过的事。

- **标题-结构-全文三次确认**：不闷头写 2000 字等用户说"方向不对"。两个真正不同的标题方向→3-5 段结构→全文，每一步等用户确认再往下
- **事实/解释/假设三层标注**：文章里每句话属于哪一层？用户亲历的事实、你对事实的理解、还在验证的假设——分不清就退回重写
- **仿写降级为可选技巧**：仿写只是第 3 层里"怎么写"的一种参考方式，不是产品的第一个入口
- **去 AI 味自检清单**：开头直接进场景不写背景综述、不堆"不是……而是……"句式、不用"在当今""随着发展"——AI 写完自己先过

### 第 4 层：渠道发布——"工具是适配器，不是产品本体"

**底层洞察：** 排版和发布是最后一公里的管道。产品价值不在这里，但这里做得不好前面的功夫全白费。

- **商业连接可选化**：不是每篇都该带 CTA。资产卡、选题清单不推销。公众号文章要不要加连接，由 Profile 开关控制
- **阻断式审查**：多项安检——CSS 安全、图片域名、隐私泄露、事实溯源、第三方脱敏——全绿灯才放行，一项不过不能发
- **微信兼容排版引擎**：行内 CSS、金句框、卡片、对比表等组件——写到该打断的地方自己插进去，手机上不累
- **发布双模式**：API 推草稿箱（认证服务号）+ 手动粘贴指引（个人订阅号），每次只推草稿，群发必须人确认

## 怎么用——「青青搭子」系列的两种打开方式

这个工坊是「青青搭子」产品族的第一个开源成员。**聊的搭子在微信，做的工坊在 Claude Code。**

### 方式一：Claude Code 插件（完整体验，你现在看的就是这个）

```
/plugin install career-asset-studio
```

装完 AI 自动读取全部 8 个 Skill，四层自动路由。你跟 AI 说你要干嘛，它自己判断你处在哪一层。

| 你说 | AI 判断 |
|------|--------|
| "我干了十年，不知道自己有什么可写的" | → 第 1 层：启动五组挖掘问题 |
| "帮我理理能写什么方向" | → 第 2 层：五大类别归类 + 10 题测试 |
| "帮我写一篇关于 XX 的文章" | → 第 3 层：标题→结构→全文三次确认 |
| "帮我排个版发到公众号" | → 第 4 层：排版→审查→发布 |

### 方式二：青青职场搭子（微信公众号直接聊）

同属「青青搭子」系列——这个搭子放在微信公众号上，关注「**青青的AI组织观察笔记**」，菜单栏点进去就能聊，不用装任何东西、不用跳转到别的地方。

它主打前两层：陪你探索职业价值、识别职业资产、理清下一步。你在微信里直接打字，它用青青沉淀的方法陪你一句一句聊——不是急着代写，而是从真实经历里帮你把手里的牌看清楚。

**跟工坊的关系：** 两个搭子接得上。微信里的 Chatbot 负责“想清楚”，给你一份可复制的职业资产快照或交接卡；Claude Code 里的工坊负责“做出来”，继续完成资产盘点、内容创作、排版、审查和发布。聊的归聊的，做的归做的。

### 方式三：知识包——不用插件也能用

所有规则以 Markdown 公开，不依赖 Claude Code。贴到你用的 AI 工具里、做 RAG、或者当文档读都可以。

## 包里有什么

```
skills/  ⭐             ← AI 读的就是这里。四层、8 个 Skill
 ├── 主入口              → 判断你在哪层、自动路由
 ├── 职业经历挖掘        → 第 1 层：五组问题 + 四步追问 + 降级设计
 ├── 资产盘点与方向      → 第 2 层：五大归类 + 10 题测试 + A/B 分叉
 ├── 商业连接            → 第 4 层：可选 CTA，不推销也能发
 ├── 排版                → 第 4 层：微信安全 HTML，组件式排版
 ├── 配图                → 第 4 层：可选，图文不裂
 ├── 发前审查            → 第 4 层：多项安检，不过不发
 └── 发布                → 第 4 层：草稿箱 or 手动，你说了算

references/            ← 排版组件库、微信 CSS 白名单、去 AI 味指南、隐私规则
profiles/  ⭐           ← 你的配置——经历、资产、方向、读者。聊着填，不用手写 JSON
templates/ examples/   ← HTML 骨架、资产卡模板、跑通的示例
scripts/ tests/        ← 自动化验证（Python）
.github/               ← CI/CD
private/               ← 你的私密文件，不进 Git
```
